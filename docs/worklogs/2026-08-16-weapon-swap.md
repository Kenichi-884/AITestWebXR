# 2026-08-16 武器モデル差し替え（pistol-92.fbx → cyberwrath_-_revolver.glb）

担当領域: 武器 / 敵
変更範囲: `public/assets/layout.json` の `weapon` セクションとアセットファイルのみ（`src/` 以下のソースコード・サウンド・UI関連ファイルは未変更）

## 変更したファイル

- `public/assets/layout.json`（変更）
- `public/assets/revolver/models/cyberwrath_-_revolver.glb`（新規追加）
  - 元は `public/assets/cyberwrath_-_revolver.glb` に置かれていたファイルを移動
  - GLB内部のルートノードの変換行列（translation）を1箇所パッチ（詳細は後述）

## 変更内容と理由

### 1. モデルファイルの配置

`cyberwrath_-_revolver.glb` を `public/assets/revolver/models/` に移動。既存の `pistol/` フォルダはそのまま維持した。

理由: `src/gameplay/Weapon.js` が薬莢エフェクト用に `pistol/models/pistol-bullet-shell.fbx` を直接参照しているため、`pistol/` フォルダを削除・改変すると無関係な薬莢エフェクトが壊れる。武器本体のみ独立したフォルダに分離した。

### 2. layout.json の weapon 設定を新モデルに切り替え

- `modelFile`: `pistol-92.fbx` → `cyberwrath_-_revolver.glb`
- `modelPath`: `/assets/pistol/models/` → `/assets/revolver/models/`
- `texturesPath` を削除

理由: GLBはテクスチャを内包する形式のため、FBX用の別テクスチャ指定は不要（`SceneManager.js` 側で拡張子により `GLTFLoader`/`FBXLoader` を自動切り替えする既存ロジックがそのまま使える）。

- `slideNodeName`: `"Cube001"` → `""`

理由: このGLBはメッシュが単一ノードに結合されており、スライド（引き金の可動部）用の独立したノードが存在しないため無効化。

### 3. スケール調整

- `scale`: `0.0002` → `0.062`（xr / desktop 共通）

理由: GLBファイルの頂点データ（バウンディングボックス）を解析したところ、実寸換算で全長約4.5m相当のモデルだったため、リボルバー実物大（約28cm前後）に近づく倍率を逆算した。

### 4. グリップ位置のズレ修正（原点オフセット問題）

実機確認で「武器の位置がコントローラーのグリップ位置と合わない」不具合が発生。

原因調査の結果、このGLB（Sketchfabからのエクスポート由来）はモデルの原点(0,0,0)と実際のメッシュの位置が大きくズレていることが判明。原点がズレたまま回転を加えると、原点を中心にモデル全体が振り回されるため、位置ズレと回転時の暴れが同時に発生していた。

対処: ソースコードは変更せず、GLBファイル内部のルートノードの変換行列（translation）に補正値を直接書き込み、モデルの重心を原点(0,0,0)に再センタリングした。あわせて `position` / `rotation` を一旦 `[0,0,0]` にリセットし、調整の土台を作り直した。

### 5. 回転（向き）の1回目修正

実機写真で、銃の「上向き軸」がほぼ真下を向いて拳の上に横倒しになっていることを確認。

GLB頂点データからモデル全体のバウンディングボックス軸を使って銃身方向・上方向を推定し、回転値を算出。

`rotation`: `[0, 0, 0]` → `[0, -29, 142]`

### 6. 回転（向き）の2回目修正（精度向上）

再度実機写真を確認したところ、銃口が上を向きすぎている（角度誤差が残っている）ことが判明。

原因調査の結果、5. の計算はモデル全体（銃口〜グリップ下端までの対角線）を発射方向として使っていたため、下向きに傾くグリップの影響で銃身の向き推定がズレていたことが分かった。

対処: 頂点データからバレル部分（グリップより手前の細長い区間）のみを主成分分析（PCA）で抽出し、銃身の実際の向きを再計算。計算結果は、その回転を適用した状態のモデル全頂点を自前でレンダリングして検証し、バレルが水平に前方を向く自然なリボルバー形状になっていることを確認した。

`rotation`: `[0, -29, 142]` → `[-8, -38, -151]`
